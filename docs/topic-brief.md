# 课题简介：Where to Reuse, Where to Learn（WRWL）

**一句话**：机器人用 RL 学新任务时，旧任务的策略在大多数步骤上可以直接照抄，只有少数「关键而且冲突」的决策必须自己学。WRWL 用数学定义的关键度，逐个决策决定照抄还是自学，把学习预算集中到关键决策上。目标是任务越多，新任务学得越快。

**要解决的问题**：迁移 RL 里，直接微调和 kickstarting（用 KL 把新策略拉向旧策略）都是全局照抄。在冲突的决策上会产生负迁移，比如从方块哪一面推、工具怎么钩。从零训练又白白浪费了能复用的部分。

**数学**（Y 为二值成功；Q(s,a) 为这一步做 a、之后按熟练策略走的成功概率）：
1. **关键度**：c*(s) = Var_{a~π*_τ} Q(s,a)，其中 π*_τ ∝ π_base·exp(Q/τ)。积分关键度 c̄(s) = 2τ²·KL(π*_τ‖π_base)。定义借用 Karino 2020、Li 2026、Russo 2026。
2. **方差预算**：在确定性仿真里，p(s₀)(1−p(s₀)) = E[Σ_t c(s_t)]，即一个回合结局的不确定性可以分解到各步决策上。SGS 和 AlphaNIST 按 p(1−p) 选择从哪个起点开局；c 则进一步指出回合里哪一步真正决定结局。
3. **照抄代价引理（新）**：J(π*) − J(π) ≤ Σ_t E[√(χ²(π‖π*)·c*)]。照抄造成的亏损集中在「关键 × 冲突」的决策上。只在一部分决策上照抄时，有对应的屏蔽上界。
4. **更新规则**：协变 PPO，每回合的 KL 预算固定，和控制频率无关。只作为理论依据，不作为卖点。

**方法**：
- **共享隐空间**：把旧任务的 RL 专家蒸馏成一个共享网络。输入是按槽位统一的观测（机器人、被移动物体、工具、目标、目的地），网络主干就是隐空间。
- **关键度探针**：在旧任务上用分支 rollout 测出金标准关键度，即恢复仿真状态、换不同的第一个动作块、再多次续跑。然后在隐空间上训练一个探针来预测它。
- **零样本预测**：新任务刚开始从不成功，自己测不出关键度，所以用探针零样本预测。
- **门控照抄**：PPO 损失里加一项门控 KL：g(s)·KL(π_θ‖p_L)。只有同时满足三个条件才照抄：预测的关键度低、检索到的几个源策略意见一致、状态是熟悉的。先验用防御性的混合 ½p_L + ½π_base。新任务开始有成功之后，改用实测的照抄代价 V − E_prior Q 来门控。
- **递增入库**：新任务学完后并入库，按关键度加权做别名分离。观察学习时间是否随着库变大而下降。

**平台**：ManiSkill3 GPU 仿真（可以恢复任意状态），Panda 机械臂，state 观测。源任务是 PushCube、PullCube、PickCube、StackCube、PokeCube；新任务包括 PlaceSphere、LiftPegUpright 等。只用一张 RTX 5090。

**闸门**：
- **G1**：前提成立。
- **G2（D1）**：轮流留出一个任务，零样本预测它的关键度。要求 Spearman ≥ 0.4、前 10% 的 AUROC ≥ 0.75，并且比 p(1−p)、原始状态近邻、手工接触特征都高 ≥ 0.05。
- **G3**：最小方法在冲突任务上比最好的基线少 ≥ 25% 的步数，在一致的任务上不吃亏。

**第一晚的初步结果**：
- 源任务专家的成功率在 0.82–1.00 之间。关键度标签的分半一致性 Spearman 为 0.53–0.91。关键度高度稀疏：PushCube 和 PullCube 的 c* 中位数是 0。
- **照抄机制自检**：源策略就是标准答案时，从零初始化加上 KL 项，2 轮 PPO 就到了 91% 成功率，比从零训练快 10 倍。前提是关掉 PPO 的 KL 早停。
- **D1 预览没过**。设置：用 6 个任务训练、留 1 个测，隐空间来自行为克隆蒸馏。结果：
  - 隐空间探针的 AUROC 约 0.6，没赢过原始观测和「只看剩余时间」；
  - c* 很大一部分被 p(1−p) 这个上界解释掉了，用真实 p(1−p) 排序的 AUROC 是 0.83；
  - 扣掉这一部分后，几乎没有能跨任务迁移的信息；
  - 给新任务 16 个带标签的状态，AUROC 也只到 0.64。
- 稠密奖励下已经有明显的负迁移：推的方向转 90° 及以上时，直接微调、全局照抄和两种手工门控都比从零慢 1.8–4 倍，或者 5M 步内到不了 80%（3 个 seed）。初稿写的是「转 90° 时微调更快」，那只是 seed 1 的结果，已更正。

**和最接近工作的区别**：
- **AlphaNIST**：标准 PPO + reset 状态库 + SGS 起点采样 + 二值奖励 + 大规模并行，调的是「从哪里开局」。WRWL 调的是「回合里每一步照抄还是自学」，两者可以叠加。
- **kickstarting、Distral**：在所有状态上都做 KL，是全局照抄。
- **CUP、QMP**：按 Q 值逐个状态选择用哪个策略，需要新任务的价值估计。

**主要风险**：
- D1 被平凡的预测量解释掉，比如 p(1−p)、剩余时间、接触特征；
- 收益其实来自 kickstarting 本身；
- state 观测的平台偏简单；
- 和 critical forks（Li 2026）、action influence（Russo 2026）、Memory Anchors 撞车。
