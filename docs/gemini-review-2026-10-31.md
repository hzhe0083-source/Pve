# Gemini 对课题简介的评价（2026-10-31 凌晨，原文转录）

> 输入是 [topic-brief.md](topic-brief.md)。以下为 Gemini 回复的原文，公式按原样保留（部分 LaTeX 在复制时丢失）。

WRWL（Where to Reuse, Where to Learn）的理论切入点非常漂亮，但你第一晚跑出的"D1 探针失败"和"稠密奖励下无负迁移"恰恰给你敲响了最及时的警钟——这两个现象不是工程 Bug，而是直接暴露了当前「零样本预测 c^*」主线在数学与信息论上的结构性矛盾。
好消息是：你的方差预算恒等式（公式 2）和照抄代价引理（公式 3）本身含金量极高。只要把核心叙事从"跨任务零样本猜 c^*"扭转到真正贴合引理 3 的"关键度 \times 冲突度双因子门控"，这篇工作依然具备冲击 ICLR / NeurIPS / CoRL 的潜力。

## 1. 新颖性与顶会潜力评估
- 理论亮点：
  - 照抄代价引理 J(\pi^*) - J(\pi) \le \sum_t \mathbb{E}[\sqrt{\chi^2(\pi \parallel \pi^*) \cdot c^*(s_t)}] 把负迁移上界解耦为任务内决策关键度 c^*(s_t) 与跨任务策略冲突度 \chi^2(\pi \parallel \pi^*) 的乘积。
  - p(s_0)(1-p(s_0)) = \mathbb{E}[\sum_t c(s_t)] 把轨迹级的结局不确定性分解到时间步上，将 SGS/AlphaNIST（管起点）与逐状态正则化（管过程）统一起来。
- 致命短板：门控设计与引理 3 自相矛盾。引理 3 说亏损集中在「关键 \times 冲突」上，但门控却是"预测的关键度 c^* 低才照抄"。
  - 共性瓶颈（高 c^*，低 \chi^2）：如夹爪闭合抓取的瞬间、对准插孔的瞬间，源策略在新任务上完全正确，现在的门控却在这里关掉照抄。
  - 冲突瓶颈（高 c^*，高 \chi^2）：如推方向转 90° 时的切入侧面，这里才真正需要关掉照抄。
  - 把"高关键度"直接等同于"不能照抄"是逻辑链条上最大的漏洞。

## 2. 「零样本预测关键度」是否站得住
结论：完全站不住脚。建议放弃"在 BC 隐空间上零样本预测新任务 c^*(s)"。
- 由公式 2，p(s_t)(1-p(s_t)) = \mathbb{E}[\sum_{k=t}^T c(s_k) \mid s_t]，即 p(1-p) 是未来剩余关键度的尾和，单步 c(s_t) 是其一阶差分（离散风险率）。操作任务中 p(1-p) 在接触前维持平台，过了接触决策点瞬间掉到 0，所以 c^* 是稀疏脉冲。
- 脉冲位置取决于新任务的几何接触边界。BC 隐空间双重失明：BC 在时间步上均匀加权，关键接触步被平滑掉；BC 只见过成功轨迹，没见过反事实分支，不知道新任务目标改变后动力学奇异点在哪。所以除了剩余时间或接触特征这种平凡相关性外，信息论上不可能零样本预测新任务的分岔点。

重构方案：
- 方案 A（最推荐）：两阶段「冲突-关键度」门控。
  - 冷启动（新任务成功率 = 0）：用源策略库自带的积分关键度 \bar{c}_{prior}(s) = 2\tau^2 KL(p_L \| \pi_{base}) 和多源策略分歧度。源策略一致、处于接近阶段时强照抄；进入接触区（由距离/接触特征或高 \bar{c}_{prior} 触发）且新旧任务的目标-物体相对几何发生偏移时，降低门控权重、注入探索噪声。
  - 在线提纯（新任务成功率 > 5%）：切换为实测照抄代价 \Delta Q_{copy}(s) = V_\theta(s) - \mathbb{E}_{a\sim p_L} Q_\theta(s,a)，即 -\hat{A}(s, a_{prior})。新任务价值函数成型后，TD 误差方差 Var[r + \gamma V(s_{t+1}) - V(s_t)] 是单步关键度 c(s_t) 的在线无偏估计，-\hat{A}(s, a_{prior}) 衡量冲突度，不需要跨任务零样本探针。
- 方案 B：在线轻量级微分支探测。机械臂进入离物体小于 \delta 的交互区时，用 GPU 从当前状态复制 K=4–8 个分支（一半执行源策略，一半执行探索策略），往前短跑 H=15 步，在线观测局部回报/价值分化。

## 3. 实验设计漏洞
- 漏洞一：稠密奖励破坏理论前提并掩盖负迁移。理论建立在二值奖励上；稠密奖励下每一帧都有指向新目标的梯度，旧策略省去了伸手靠近，一碰方块稠密奖励就把策略拉向新方向，所以直接微调很快。主实验必须切到二值成功奖励；只有那样，全局 kickstarting 才会出现灾难性负迁移，门控才能展现数倍加速。
- 漏洞二：冲突任务对的物理冲突太弱。推方向转 90° 只是目标槽位变了，动作原语没变。建议：接触拓扑反转 PushCube → PickCube；施力方向反转 PokeCube → PullCube；姿态奇异点冲突 PickCube → LiftPegUpright。
- 漏洞三：缺少退火 kickstarting 与简单启发式门控基线。必须加「手工距离门控基线（Distance-Gated Kickstarting）」：末端离物体 > 5 cm 照抄，≤ 5 cm 自己学。并在"近距离依然需要照抄"的任务上击败它，例如 PickCube → StackCube（抓取那一步距离 < 5 cm 但动作一致，必须照抄；只有放到第二个方块上方时才冲突）。这能证明只看接触距离不够，必须结合冲突度。

## 4. 与 AlphaNIST/SGS、Kickstarting、CUP/QMP 的区分

| 方法类别 | 代表工作 | 作用维度 | 是否需要新任务中间状态库 | 稀疏奖励破冰期（Q≡0）表现 | 核心局限 |
|---|---|---|---|---|---|
| 起点课程采样 | SGS, AlphaNIST | 回合起点分布 | 需要 | 无缓存时退化 | 不改变回合内的探索效率 |
| 全局策略正则 | Kickstarting, Distral | 全轨迹所有状态 | 不需要 | 能走完前段，但卡在冲突瓶颈 | 关键冲突步严重负迁移 |
| 基于价值的策略选择 | CUP, QMP | 逐状态动作/策略选择 | 不需要 | 失效（初期 Q 全为 0，盲选） | 没成功就没有好 Q 的死锁 |
| 关键-冲突双因子门控 | WRWL | 逐状态选择性 KL 门控 | 不需要 | 靠先验一致性度过前段，在分歧点释放探索 | 随技能库增长单调加速 |

- 对标 AlphaNIST/SGS：方差恒等式揭示两个正交轴，SGS 挑 p(s_0)≈0.5 的起点最大化左边的总方差输入，WRWL 把探索算力分配给右边存在跨任务冲突的 c(s_t) 项。杀手锏实验：新任务没有 reset 缓存时 SGS 无法启动（所有起点 p(s_0)=0），WRWL 能从零成功破冰，生成第一批成功轨迹喂给 SGS；WRWL + SGS 比任何一方都快。
- 对标 CUP/QMP：画"首次达到 10% 成功率所需步数"随技能库大小 N 的曲线，证明 CUP/QMP 因初期 Critic 无信号长期卡在 0%，WRWL 依靠先验结构门控近乎零样本破冰。

## Go / No-Go 建议
- 调整 G2（D1）：不要求探针零样本预测新任务的绝对 c^*，改为验证「源策略积分关键度 + 源策略分歧度 + 在线 Advantage 落差」能否在二值奖励下准确识别冲突瓶颈步。
- 主实验切到二值奖励 + 强拓扑冲突任务对（PushCube → PickCube、PokeCube → PullCube），先跑出"全局 kickstarting 严重负迁移，而 WRWL 比从零训练和全局微调都快 30% 以上"的核心曲线。
